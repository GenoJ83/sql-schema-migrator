# Observability, Distributed Tracing & Metrics Guide

## Core Telemetry Capabilities
- **W3C Distributed Tracing**: Trace context propagation across asynchronous boundaries.
- **Latency Histograms**: Sub-millisecond quantile distributions (P50, P90, P99).
- **Prometheus Metric Exposition**: Production-grade gauges and monotonic counters.
- **Proactive Health Probes**: Automated system degradation alarms.
